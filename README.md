# Bilhete — Sol da Sorte (download do APK)

Aplicativo do vendedor do **Bilhete Online / Sol da Sorte** (SLB — Sistema Lotérico da Bahia).
Este repositório serve **apenas para distribuir o APK**. O código-fonte não fica aqui.

## O que o app faz

- Carrega o concurso ativo e mostra os bilhetes disponíveis para venda.
- Monta o carrinho e fecha a venda no celular, com **PIX (QR Code)** ou dinheiro.
- Emite o cupom e compartilha com o comprador.
- Lê o **código de barras** para validar bilhetes já vendidos.
- Mostra o painel do vendedor: vendas do dia, total online, total em papel e prêmios do concurso.
- Envia as vendas para os servidores da API e avisa, em uma tela própria, quando o aparelho está
  sem internet ou quando os servidores estão fora.

## Instalar

1. Baixe o APK pelo celular Android.
2. Ao abrir o arquivo, autorize "instalar de fontes desconhecidas" para o navegador ou gerenciador de arquivos.
3. Abra o app e entre com o **login e a senha do vendedor**.
4. Em **Configurações**, confira o endereço do servidor e o e-mail do diagnóstico.
5. Em **Configurações → Impressora**, pareie a impressora Bluetooth.

Requisitos: Android 7.0 ou superior. Este APK é de **teste (debug)**.

## Suporte

Em **Configurações → Diagnóstico de conexão** ficam registradas as falhas de rede do aparelho;
o botão **Enviar por e-mail** manda o relatório para a equipe.
